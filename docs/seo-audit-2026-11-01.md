# GutenKu SEO audit — 1 November 2026

## Search Console evidence

Property: `sc-domain:gutenku.xyz`. Search performance covers 31 July–30 October 2026; coverage was last updated 23 October.

- 49 clicks, approximately 1,350 impressions, 3.6% CTR, average position 16.4.
- `/game`: 45 clicks / 890 impressions. `/haiku`: 1 / 384. Homepage: 1 / 68.
- “haiku generator”: 177 impressions, zero clicks. This is an opportunity for a later query-level position and search-intent review, not evidence that changing a title alone will improve rankings.
- Coverage: 5 indexed URLs, 3 redirect exclusions, 1 crawled but unindexed URL.
- Redirect exclusions are `http://gutenku.xyz/`, `http://www.gutenku.xyz/`, and `https://www.gutenku.xyz/`. These are expected canonicalization variants; do not remove the redirects just to clear this report.
- The crawled but unindexed URL is `/sitemap.xml`, not a content page. A sitemap need not appear in search results.
- HTTPS report: 4 HTTPS URLs, zero non-HTTPS. Core Web Vitals: insufficient field data, not a passing score.

## Remaining production checks

Direct requests to `gutenku.xyz` from this environment returned the organization's Cato web-filter warning instead of origin content. No filter bypass was attempted. This does **not** establish that Google is blocked by that filter or identify the cause of Google's separate fetch failure.

After deploying these code changes:

1. Verify `/sitemap.xml` returns HTTP 200 with XML, and `/robots.txt` is accessible, from outside the filtered network. Check origin/CDN access logs and bot rules for Googlebot failures. Do not loosen security rules without evidence.
2. Confirm every sitemap URL returns indexable content and a matching canonical. Confirm unknown URLs return HTTP 404, rather than the homepage fallback.
3. Recheck Search Console for a successful sitemap read and discovered URLs. Do not mark the fetch failure resolved just because submission was accepted.
4. Review the two article URLs absent from the current indexed-page count using URL Inspection after the sitemap is fetched. Counts alone do not identify the exact missing URLs.
5. Measure mobile performance with a fresh Lighthouse/PageSpeed run. Search Console currently has insufficient Core Web Vitals data; no performance conclusion is supported.

Code changes are local and have not been deployed. The resubmission used the current production sitemap, not the locally generated replacement.
